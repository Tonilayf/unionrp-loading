# UnionRP 2026 — Loading Screen

Экран загрузки для Garry\x27s Mod / Union RP City 17 CopyNew2026.

## GitHub Pages

1. Создайте публичный репозиторий `unionrp-loading`.
2. Загрузите `index.html` и `.nojekyll` в корень репозитория.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Адрес: `https://ВАШ_ЛОГИН.github.io/unionrp-loading/`.

## Garry\x27s Mod

Укажите опубликованный URL в параметре `sv_loadingurl`.
